# 项目实验区

`experiments/` 用于保存独立于正式业务启动流程的学习实验、压测脚本、故障注入工具和实验结果。

当前实验主题：

- [高并发实验](./concurrency/README.md)：实验清单与实施顺序
- [实验执行手册](./concurrency/docs/EXPERIMENT_GUIDE.md)：隔离、指标、步骤和报告模板
- [实验结果索引](./concurrency/results/README.md)：已归档报告

实验区遵守以下约定：

- 默认只连接实验专用数据库和容器卷，不操作日常开发数据。
- 压测脚本不进入前端运行时，也不参与后端、前端和推荐服务的生产构建。
- 先记录原始实现的基线，再修改业务代码并复用同一场景复测。
- 故意制造的慢响应、异常和网络故障放在 Stub 或实验配置中，不长期写入正式业务逻辑。
- 每次实验都同时检查性能指标和最终数据正确性。
