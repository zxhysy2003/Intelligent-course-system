# 实验结果

本目录保存脱敏后的实验报告和必要的结果摘要。

建议结构：

```text
results/
└── CON-01/
    ├── baseline.md
    ├── optimized.md
    └── assets/
```

结果文件需要记录 commit、日期、机器环境、数据规模、并发模型和运行配置。禁止保存 JWT、真实密码、用户隐私、完整数据库导出或未脱敏日志。
